结构化总结

Spring 是什么

轻量级 Java 框架
  • 目标：让开发者专注业务逻辑。
  • 两大核心特性：依赖注入 (IOC) 与 面向切面编程 (AOP)。
  • 生态延伸:Spring Boot(约定优于配置)、Spring Cloud(微服务)。

依赖注入 (IOC / DI)

控制反转 · 三种注入
  • IOC 是设计原则(控制反转);Spring 用 DI 实现,容器被动注入,组件不感知容器。
  • 构造器注入:依赖不可变(final)、非空、易测;但无法解循环依赖。官方推荐用于必需依赖。
  • Setter 注入:可解循环依赖,适合可选依赖;依赖可变。
  • 字段注入:最简洁但违背不可变、难测试。

DI 原理与三级缓存

BeanDefinition → 循环依赖
  • 流程:BeanDefinition 注册 → 注入点收集 → 依赖查找解析 → 依赖写入。
  • BeanDefinition 是 Bean 图纸,三种来源(XML / 注解扫描 / @Bean),统一存入 beanDefinitionMap。
  • 三级缓存:实例化后把 ObjectFactory 放入 singletonFactories,是解循环依赖的核心。
  • 歧义消除:@Primary → @Priority → 字段名匹配,否则抛 NoUniqueBeanDefinitionException。

Bean 生命周期

9 个阶段
  • 加载 BeanDefinition → 实例化(构造器注入) → 属性填充(三级缓存) → Aware 回调。
  • 前置处理(@PostConstruct) → 初始化(InitializingBean/init-method)。
  • 后置处理:AOP 代理在此生成(事务、切面此时生效) → 放入单例池 → 销毁(@PreDestroy)。

面向切面编程 (AOP)

动态代理 · 责任链
  • 把横切关注点(日志、事务)模块化为切面,动态织入连接点。
  • 术语:连接点 / 切点 / 通知(Before/After/AfterReturning/AfterThrowing/Around)/ 切面 / 织入。
  • 两种代理:JDK(要求接口,InvocationHandler)、CGLIB(生成子类,ASM)。
  • 核心引擎 AnnotationAwareAspectJAutoProxyCreator:收集切面为 Advisor + 创建代理;拦截器链走责任链模式。

事务管理

ACID · 声明式 = @Transactional + AOP
  • 三大接口:PlatformTransactionManager(管理器)、TransactionDefinition(定义)、TransactionStatus(状态)。
  • 声明式:@EnableTransactionManagement → TransactionInterceptor(实现 MethodInterceptor)执行事务逻辑。
  • 7 种传播行为四组:一起干(REQUIRED/SUPPORTS/MANDATORY)、单干(REQUIRES_NEW/NOT_SUPPORTED/NEVER)、特殊(NESTED)。
  • 失效根源全在 AOP 代理:类内自调用、非 public 方法、异常被吞、异常类型不匹配、引擎不支持、多线程、传播行为错误。

Spring Boot

自动装配 · 约定优于配置
  • 把可配置性固化为约定:自动装配、起步依赖、内嵌容器、配置文件。
  • @SpringBootApplication = @SpringBootConfiguration + @ComponentScan + @EnableAutoConfiguration。
  • 自动装配靠 AutoConfigurationImportSelector 读取 AutoConfiguration.imports(3.0 前为 spring.factories),按条件注解装配。
  • 自定义 Starter:starter(聚合依赖) + autoconfigure(自动配置类 + imports 文件)。

Spring Cloud

微服务一站式方案
  • 建立在 Spring Boot 之上,每个组件以 Starter 形式提供;国内多用 Cloud Alibaba。
  • 服务注册发现/配置:Nacos;远程调用:OpenFeign;容错:Sentinel;网关:Gateway;链路追踪:Sleuth+Zipkin。
  • Nacos:动态服务发现 + 配置管理,3.x 起扩展 AI 管理中心(MCP/Agent/Prompt)。
