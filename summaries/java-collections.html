Collection · 单列集合

ArrayList

List · 动态数组
  • 查询快 O(1)，尾部写入均摊 O(1)
  • 扩容：首次 add 扩到 10，满后 1.5 倍
  • 线程安全：否

LinkedList

List · 双向链表
  • 写入快 O(1)，查询慢需遍历
  • 线程安全：否

HashMap

数组 + 链表 + 红黑树
  • JDK1.8：+红黑树 O(logn)
  • 扩容：负载因子 0.75，首次 put 扩到 16
  • 线程安全：否

ConcurrentHashMap

线程安全 · 高性能
  • JDK1.8：CAS + synchronized
  • 线程安全：是

高频问答 · FAQ

ArrayList 和 LinkedList 的区别？
ArrayList 基于动态数组，查询 O(1)；LinkedList 基于双向链表，写入 O(1)。
为什么用红黑树而不是 AVL？
红黑树以少量查询性能换取更少旋转，整体成本更低。
